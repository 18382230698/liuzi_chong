# 六子冲棋

纯本地单文件网页棋类：人机对战，无外部依赖。

## 运行

```sh
python -m http.server 8080
```

打开 http://localhost:8080

也可直接双击 `index.html`（部分浏览器对音频/动画更友好时建议用本地服务）。

## 说明

- **对战**：人机对战 / 双人对战（同设备轮流，无 AI）
- **标准模式**（默认）：仅二打一
- **全规模式**：额外启用夹吃、挑吃，单子可飞
- **先手**：红方先 / 黑方先 / 猜拳定先
- 胜负：敌方减至一子或无法行动即胜
- AI（仅人机）：超简=随机；易/中/难=Minimax；地狱=深搜 + 置换表
- 猜拳：人机对 AI；双人则红先选、黑后选，动画亮出，平局重来
- 纯本地单文件：无 CDN、无外链资源；音效为 Web Audio 程序合成
